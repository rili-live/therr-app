therrads

Internal campaign management and performance-analysis tool for the Google Ads API

Therr, Inc.  ·  Prepared for a Google Ads API Basic Access application  ·  September 2026

1. Summary

therrads is an internal, first-party command-line tool that Therr, Inc. uses to create and manage Google Ads campaigns for its own advertising account, and to read that account's performance back alongside its own product analytics.

It is not a product, and it is not offered to anyone. It is not sold, licensed, distributed, resold, or made available to third parties. It manages no client accounts. It has exactly one operating account and one intended set of users: the internal team at Therr, Inc. that operates the advertiser.

2. Business model

Therr, Inc. builds consumer mobile applications. The application being advertised, Friends with Habits, is a habit-tracking app built around accountability partners: each habit is a "pact" with a friend, both parties check in daily with photo or note proof, and each can see when the other misses a day.

Revenue is direct-to-consumer through Google Play Billing, on a freemium model:

  • Free tier — up to five active habits, daily check-ins, streak tracking, partner activity feed and reminders. No card required.
  • Founder Unlock — a one-time $20 USD purchase granting every paid feature for life, limited to the first 5,000 accounts. Processed by Google Play Billing and verified server-side.

There is no advertising inventory in the app, no data brokerage, and no resale of any Google service or data. Google Ads is used solely to acquire users for the company's own application.

3. What the tool does

Campaigns are defined as version-controlled YAML files in the company's repository, reviewed like code, and applied to the Google Ads account by the tool. Performance is read back and joined against the company's own Google Analytics 4 properties and product database, so that spend can be evaluated against outcomes the Ads account alone cannot see.

4. Intended audience

The operators of Therr, Inc.'s own advertising account. The tool is run from a terminal on a company workstation, against a single account, by internal staff only.

It has no user interface for anyone else, no hosted deployment, no multi-tenancy, no notion of a client or a sub-account, and no mechanism by which a third party could use it. Should the company ever wish to offer such a service, it understands that would be a materially different application requiring Standard access and a separate review.

5. Safety controls

Because this tool spends money, its safeguards are its most deliberate feature.

  • Nothing mutates without --confirm. Every mutating command without that flag prints exactly what it would send and exits having sent nothing.
  • Campaigns are created PAUSED. Enforced by an automated test over every campaign file, so a spec cannot turn a review step into a billing event.
  • Client-side budget ceilings. A per-campaign cap and an account-wide cap are checked before any request is sent, because two campaigns each under the per-campaign cap are still twice the intended spend.
  • Exact-decimal currency conversion. All dollar-to-micros conversion goes through one audited function using decimal arithmetic, so a rounding or unit error cannot become an overspend.
  • Read-only product database access, over a cursor explicitly set read-only.
  • 104 automated tests covering the budget guards, spec validation, the plan builder and the analysis rules. None of them requires credentials, which is deliberate: a test that reaches for a live account is a test that stops being run.

6. Worked example

Below is the real, unedited output of campaign plan, the read-only command an operator runs before applying anything. It enumerates every API operation that campaign apply would send, and sends none of them.

$ ./therrads campaign plan campaigns/habits-app-install.yaml

CAMPAIGN PLAN — FwH-App-US-Installs-2026Q3
  spec:      campaigns/habits-app-install.yaml
  kind:      app_install
  status:    PAUSED  (created paused unless the spec says otherwise)
  budget:    20.0 USD/day = 20.00 USD
  bidding:   OPTIMIZE_INSTALLS_TARGET_INSTALL_COST @ target CPA 2.5
  targeting: locations=['2840'] languages=['1000']

OPERATIONS (6):
  CREATE  CampaignBudget     FwH-App-US-Installs-2026Q3 — daily budget  20.0 USD/day, STANDARD, not shared
  CREATE  Campaign           FwH-App-US-Installs-2026Q3  APP / MULTI_CHANNEL, status=PAUSED
  CREATE  CampaignCriterion  geo:2840  location target
  CREATE  CampaignCriterion  lang:1000  language target
  CREATE  AdGroup            FwH-App-US-Installs-2026Q3 — ad group  App campaigns allow exactly one
  CREATE  AdGroupAd          app ad  5 headlines, 4 descriptions

WARNINGS (advisory — apply will proceed):
  ! assets.videos is empty. App campaigns without a video are limited to Search and a
  ! narrow Display slice: expect a fraction of the reach at a higher CPI.
  ! Daily budget 20.00 USD is under 50x the target CPA (125.00 USD recommended).

Nothing sent. To execute:
  ./therrads campaign apply campaigns/habits-app-install.yaml --confirm

7. Data handling

  • Credentials — developer token, OAuth client and refresh token — are stored in a local file that is excluded from version control and never leaves the operator's workstation.
  • Data retrieved from the Google Ads API is aggregate campaign performance: impressions, clicks, cost, conversions, ad group and search-term totals. No personally identifiable information is requested, stored, or derived.
  • Reports are written to local files for the operator's own use. Nothing retrieved from the API is published, shared with third parties, or sold.
  • The tool makes no use of the Google Ads API on behalf of any party other than Therr, Inc.
