# Ad creative — Friends with Habits

Image assets for the Google Ads campaigns in [`../campaigns/`](../campaigns/).

**`therrads campaign apply` does not upload any of this.** The tool sends text
assets only — `assets.images` / `assets.videos` in a spec are validated and
counted but never sent, because binary assets need a separate `AssetService`
upload the tool does not perform. Everything here is attached by hand in the Ads
UI after the campaign is created. The spec validator warns about this on every
run.

---

## What is here

Nine frames, three concepts × three ratios, all generated by
[`build_frames.py`](build_frames.py) from screenshots and the logo already in
this repo.

| Ratio | Size | Ads slot |
|---|---|---|
| 1.91:1 | 1200×628 | landscape (min 600×314) |
| 1:1 | 1200×1200 | square (min 300×300) |
| 4:5 | 1200×1500 | portrait (min 480×600) |

| Concept | Screenshot | Line |
|---|---|---|
| `streak` | active streak widget | *Don't break the streak.* |
| `pact` | multi-habit dashboard | *Every habit is a pact.* |
| `partner` | first-pact onboarding | *Someone else is counting on you.* |

Upload all nine. App campaigns assemble combinations themselves, and an unfilled
ratio is inventory the campaign cannot bid on.

## Regenerating

```bash
python3 scripts/google-ads/assets/build_frames.py
```

Re-run it whenever the app's UI changes. A stale creative is worse than none —
it advertises a product that no longer looks like that. The generator reads its
sources with `git show` from `niche/HABITS-general`, so it works from `general`
where the campaign specs live; it needs Chrome and `rsvg-convert`.

## Design notes

The purple (`#3B2A4E`) is sampled from the app's own check-in button and the
amber (`#EDBB3C`) from the logo's crest, so the ad and the thing it opens are
the same brand rather than two interpretations of it. Type is Lexend, matching
habits.therr.com, so a searcher who has seen the landing page sees the same face.

Headlines here stay short and deliberately do **not** restate the value
proposition — Ads composes these frames with the headlines and descriptions in
`campaigns/*.yaml`, and an image that argues its own case competes with the text
asset beside it.

Three of the six available screenshots are unusable as ad creative and the
generator says so in a comment: the onboarding slides carry their own headline
burned into the image, so a frame that supplies a headline ends up with two.

## Still missing, and it is the expensive one

**Video.** An App campaign without one is limited to Search plus a narrow
Display slice — a fraction of the inventory at a materially higher CPI, and it
is the single largest lever on what an install costs.

It cannot be produced here at all: App campaign video assets must be
**YouTube-hosted**, so the deliverable is a URL, not a file, and a channel for
Friends with Habits is a prerequisite. One 15–30s portrait clip is enough to
start. Tracked in `docs/WORK_IN_PROGRESS.md § Paid acquisition`.

Also outstanding, though it is a Play requirement rather than an Ads one: the
1024×500 feature graphic, in `docs/niche-sub-apps/HABITS_PLAY_LISTING.md`.
