## Decisions
- Feed is NOT friends-only: it is distributor-activated public HABITS-brand
  thoughts; it only looked friends-only because shared check-ins are the sole
  HABITS content source. `BRAND_THOUGHTS_VISIBILITY[HABITS] = [HABITS]`.
- Root cause of the share toast: users-service prod pod had no GCS bucket /
  credentials / Sightengine env → `storage.bucket('')` throws (500); side
  effect: every proof moderation fails closed → flagged.
