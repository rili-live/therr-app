## Session 2 — `general`: CircleCI build/publish manifest

### Goal
Debug CircleCI `docker_build_test_publish_images` failing on the `general` → `stage`
merge at `e4790de8`: `docker push therrapp/client-web-stage` → "An image does not
exist locally with the tag".

### Root cause
`build.sh` skipped all 8 services as "No Changes" (green), while `publish.sh` — the
identical predicate, same job, same checkout — found `therr-client-web` changed and
pushed a tag nothing had built. The predicate in `_bin/lib/has_diff_changes.sh`
counted with `NUM=$(git diff ... | wc -l)`, which reports `wc`'s exit status, not
git's. Git failing (unresolvable rev / missing object / shallow checkout) produced
zero lines, and `[[ 0 -gt 0 ]]` is false — so "git could not answer" and "nothing
changed" were the same answer. Silent skip.

### Deliverables (uncommitted, on `general`)
- `_bin/lib/has_diff_changes.sh` — `_count_diff_files` checks git's exit status and
  aborts, leaving git's message in the job log.
- `_bin/lib/build-manifest.sh` (new) — `.build-manifest.tsv`; build.sh records the
  tags it built, publish.sh pushes that list. Absent file = build never ran (hard
  error); empty = built nothing. Includes `assert_image_exists`.
- `_bin/cicd/build.sh` / `publish.sh` — manifest write/read; predicate demoted to a
  cross-check that fails naming both steps; ledger row taken from the pushed tag.
- `_bin/lib/tests/build-manifest.test.js` (new) — verified to fail against the
  pre-fix predicate.
- `.circleci/config.yml` — `setup_remote_docker: version: default` on all 5 (hygiene,
  not the cause; the build never reached `docker build`).
- `docs/DEPLOY_PIPELINE.md` — new "build.sh hands publish.sh a manifest" section.

### Decisions
- Did NOT pin an explicit Docker number (26/27 need Gen2 resource classes); `default`
  is the documented alias and a wrong string would break all 5 jobs.
- Left `sources_changed_between`'s `2>/dev/null` fail-open alone — it has a deliberate,
  documented `git cat-file -e` pre-check.
