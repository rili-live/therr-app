# 2026-08-15

## Goal
Three Friends with Habits features before promoting from Play open testing to
production: a $20 lifetime founder unlock (first 5,000) with a free-tier cap,
solo/personal habits, and a Journal route.

## Deliverables
Two branches, split per the general/niche rule:
- `claude/habits-production-readiness-18rctx-general` (targets `general`) —
  3 migrations (`habits.user_habits`, `lifetime_purchases`, `journal_entries`),
  Google Play verification client, lifetime/user-habits/journal handlers +
  routers + gateway routes, `assertHabitCapacity`, therr-react services/actions/
  reducer/types, service locales x3, docs. 762 unit tests green.
- `claude/habits-production-readiness-18rctx` (targets `niche/HABITS-general`) —
  Journal tab (5th), UpgradePaywall, solo-habit UI, react-native-iap wiring,
  locales x3, versionCode 23 / 0.5.0. 1363 tests green, tsc baseline clean.

## Decisions
- Google Play Billing, NOT the Stripe web checkout in the old plan doc — policy
  risk on a submission already carrying a User Data rejection, and the external
  purchase pattern requires never advertising the offer.
- Free tier caps ACTIVE HABITS (5), replacing the pact-count cap. Counting pacts
  penalised the social behaviour the app exists to encourage.
- `HABITS_LIFETIME` kept distinct from `HABITS_PREMIUM` so a future
  subscription-cancelled webhook can never revoke a lifetime buyer.
- Solo habits unlock on invite SENT, not pact accepted (fixes the dead end where
  a friend who never accepts strands the inviter). Fails closed.
- Habit cap DOES gate accepting an invite; archiving is the free escape hatch.
- Refunds honoured past 5,000 seats (buyer paid; null founderNumber + warn span).
