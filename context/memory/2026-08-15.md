## Decisions (user-confirmed up front)
- Deliverable scoped to a viability memo only — no schema/endpoints/feature code.
- Prize rail: off-platform. Host pays Therr a listing fee via existing Stripe Checkout,
  pays the photographer directly. Therr never holds prize money.
- Placement: core Therr brand, not a new niche variant.

## Key findings
- Media/geo half is mostly built: camera capture (6 flows already branch openCamera vs
  openPicker), signed uploads, ImageKit, PostGIS + maxProximity, Sightengine live.
- `habits.proofs` (20260126000008) is the design template — already has capturedAt/EXIF,
  GPS location, verificationStatus, moderationFlags. But NO mobile UI populates them.
- Verified negatives: no Stripe Connect/transfers/payouts anywhere; `includeExif` unused
  repo-wide (so `cropping: true` strips the EXIF the feature depends on); zero
  Gesture.Pan/PanGestureHandler/PagerView usage in TherrMobile/main.
- Binding constraint is two-sided liquidity at ~50 users, not technology.
