## Leaderboard XP for registration + app opens
- Goal: more users on the weekly board. Registration +10 XP once (createUserHelper, skips invite placeholder accounts); app open +1 XP, max 3/UTC day.
- Cap is a Redis INCR counter (`tryClaimAppOpenXp`, fails closed) rather than a DB ledger — loss costs at most 3 pts/day, avoids a new brand-scoped table.
- Endpoint POST /users/leaderboards/app-opens (gateway + users-service); mobile Layout calls it on launch/login/return after 60s away.
- Open: mobile tsc/lint not run (TherrMobile deps not installed in container).
