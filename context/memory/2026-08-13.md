# 2026-08-13

## Goal
Debug and improve `scripts/import-spaces` to add images + metadata to production
spaces lacking a business image or website.

## Prod baseline measured (7,526 spaces)
- Image 40% · Website 60% · Email 15% · Phone 58% · Hours 63%
- Menu 0.2% · Order 1% · Reservation 0.1% · Cuisine 0%
- 4,509 missing an image, but only 1,584 have a website to crawl
- `priceRange` is NOT NULL for every row (mostly default `2`) — price enrichment is inert
- `foodStyle` 100% NULL

## Root cause of "script does nothing"
`--limit N` applied LIMIT in SQL, *then* filtered processed IDs in JS. With
1,239 of 1,584 eligible spaces already attempted, a `--limit 50` run yielded
~11 real targets. Fixed by excluding processed IDs in SQL via
`id != ALL($n::uuid[])` before LIMIT.
