## Decisions
- localDate is a NEW column, not a reinterpretation of scheduledDate. scheduledDate
  stays UTC (per-habit streak); localDate is the user's day (daily streak). The
  23:50-Chicago case is the reason.
- Rules live in a pure no-I/O module so re-evaluation is a no-op; the ledger is
  upserted by (userId, localDate). Backdate/delete both go through one
  rewind-and-rewalk, which is what makes the freeze refund fall out for free.
- First-contact backfill walks history with freezes DISABLED, so it cannot drain
  the pool the user needs tomorrow.
- Milestone achievements fire only when the length exceeds longestStreak ever;
  the celebration screen still shows on a repeat.
- Period id IS the Monday periodStart — no periods table was added.
- All TherrMobile changes went niche-only, matching the precedent that Habits
  mobile UI does not exist on general (Dashboard.tsx is niche-only).
