Implement a weekly recap push notification and screen for Friends with Habits.

  mobile locales, in-app entry point on MyHabits.

## Decisions
- The recap's framing (perfectWeek/firstWeek/improved/steady/declined) is chosen
  once in users-service and travels on the payload. Push copy and the screen
  header are built in different services; deriving it twice is how they diverge.
- The producer rides the daily digest and asks each user "is it *your* Monday?"
  rather than adding a weekly scheduler job — there is one Cloud Scheduler firing
  and no timezone bucketing anywhere.
- No recap for a week with zero check-ins. `habitComeback` owns the lapsed user.
- Deploy order is mobile-first; a recap reaching an installed build with no
  WEEKLY_RECAP intent filter renders and opens nothing.
