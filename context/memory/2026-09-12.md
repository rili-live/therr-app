# 2026-09-12

## Goal
FWH check-in formatting: (1) shared check-in posts should not carry the
"Goals update:" cross-brand label — only composed goals do; (2) journal
check-in rows should link to their shared post or the habit detail; (3) Therr
web feed should render thought images.

## Deliverables (two PRs, split by branch)
- Shared -> general: PR #2902 (branch claude/habits-checkin-formatting-bm4658-shared)
  - HABIT_CHECKIN_THOUGHT_CATEGORY constant (therr-js-utilities)
  - shareCheckin stamps category 'habit-checkin' on the thought
  - crossBrandPostLabel suppresses label for that category; ThoughtDisplay passes category
  - JournalEntriesStore.getFeed adds sharedThoughtId to check-in meta
  - ExploreThoughts renders attached public image (getThoughtMediaUri)
- Niche -> niche/HABITS-general: PR #2903 (branch claude/habits-checkin-formatting-bm4658)
  - Journal check-in rows pressable -> ViewThought (sharedThoughtId) or HabitDetail
  - checkinAccessibility locale key x3

## Decisions
- Journal UI exists ONLY on niche branch (backend journal store is on general).
  So this was a genuine two-bucket split; label/image/backend all on general.
- Marker = thought.category rather than a new column (no migration needed;
  category already flows on every read path; kept out of ThoughtCategories).

## Merge order
Shared #2902 first, then niche #2903 (niche reads sharedThoughtId; falls back
to habit detail until #2902 merges down).
