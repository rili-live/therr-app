# 2026-08-24

## Goal
Fix three HABITS dashboard UX complaints from a device screenshot: the nav-bar
notification badge, the confusing segment filters, and the onboarding overlay
flashing on cold start.

## Deliverables (branch: niche/HABITS-general, all under TherrMobile/**)
- Badge now counts `habits.pendingInvites` (invites awaiting the user's reply)
  instead of invites they sent. Logic extracted to
  `main/components/ButtonMenu/habitsBadgeState.ts`; landing segment follows the
  badge.
- Segment "Pending" renamed to "Invites" (`pages.pacts.invitesTabLabel`) — it had
  been reusing `pages.pacts.status.pending`, the same string the status badge
  renders. Pending status badge now reads "Awaiting acceptance" / "Needs your
  reply". `getStatusText` exported from PactCard and reused by PactDetail.
- Invites/Sent segments carry inline counts; Invites has its own empty state.
- `main/utilities/habitsOnboardingCache.ts` — sticky per-user MMKV flag read
  synchronously by PactOnboardingGuard, removing the cold-start overlay flash.

## Decisions
- Badge = only what the user can act on. A badge that never clears (one sent
  invite had sat 105 days) trains users to ignore all badges.
- Onboarding flag is deliberately one-way and never cleared on logout; the
  dashboard's own empty state covers "started then abandoned everything".
- Chose the MMKV flag over persisting the `habits` Redux slice, which lives in
  therr-public-library and would have needed a separate PR on `general`.

## Icon misalignment on Habits (root cause found)
- NOT a layout bug and NOT present on Therr. `general` and `niche/HABITS-general`
  ship different TherrFont.ttf blobs.
- Commit 6e6d6882d (Apr 24) rebuilt the font from IcoMoon to add `cami-glyph`.
  The rebuild recalculated every glyph's `glyf.xMin` but left every `hmtx.lsb` at 0.
  TrueType requires lsb == xMin; when they differ FreeType slides the outline by
  (lsb - xMin), so all 95 icons drew left by their own bearing: trophy 3px,
  dots-horiz 8px, idea 11px at 24dp / 2.625 density. Matches the screenshot exactly.
- Fix: `resources/fonts/fix-icon-font-bearings.py` sets lsb = xMin. No outline
  coordinates change; all 92 shared glyphs now rasterize 0.0px from general's font.
  Guard: `__tests__/assets/therrIconFont.test.ts` (lsb == xMin + both copies equal).
- Commits 4a14ebc81, 899c441bf, 84b5c6e50 chased this in layout and could not work.
- Stays on niche/HABITS-general. general is already correct — nothing to port.
- Needs a native rebuild; fonts are native assets, Metro reload won't pick it up.
