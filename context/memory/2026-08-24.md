## Icon misalignment on Habits (root cause found)
- NOT a layout bug and NOT present on Therr. `general` and `niche/HABITS-general`
  ship different TherrFont.ttf blobs.
- Commit 6e6d6882d (Apr 24) rebuilt the font from IcoMoon to add `cami-glyph`.
  The rebuild recalculated every glyph's `glyf.xMin` but left every `hmtx.lsb` at 0.
  TrueType requires lsb == xMin; when they differ FreeType slides the outline by
  (lsb - xMin), so all 95 icons drew left by their own bearing: trophy 3px,
  dots-horiz 8px, idea 11px at 24dp / 2.625 density. Matches the screenshot exactly.
- Fix: `resources/fonts/fix-icon-font-bearings.py` sets lsb = xMin. No outline
  coordinates change; all 92 shared glyphs now rasterize 0.0px from general's font.
  Guard: `__tests__/assets/therrIconFont.test.ts` (lsb == xMin + both copies equal).
- Commits 4a14ebc81, 899c441bf, 84b5c6e50 chased this in layout and could not work.
- Stays on niche/HABITS-general. general is already correct — nothing to port.
- Needs a native rebuild; fonts are native assets, Metro reload won't pick it up.
