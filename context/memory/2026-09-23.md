# 2026-09-23

## Goal

Restyle the Friends with Habits purchase page (`UpgradePaywall`) and, in a separate
PR, add the paths that route users to it. Both TherrMobile-only, so both target
`niche/HABITS-general`.

## Deliverables

- **PR #2965** `claude/fwh-purchase-page-redesign-qyjf10` → `niche/HABITS-general`:
  founder hero card on a brand gradient (`react-native-linear-gradient`, already a
  dep), seat meter from `claimed/total`, white CTA, monthly plan as an outlined
  anchor card (primary fill only when founder is sold out), "Not now" demoted to a
  text link, 402 header shows one pip per free slot. New pure helpers in
  `routes/Habits/paywallPresentation.ts` (value anchor "costs less than N months",
  seat fill ratio, seat count formatting). Locale keys in en-us/es/fr-ca.
- **PR 2** `claude/fwh-paywall-conversion-paths-qyjf10`, stacked on PR 1:
  `source` param on every paywall navigation, reported on `habits_paywall_view` and
  both purchase events; `habits_upgrade_nudge_view` impression per surface from the
  shared `UpgradeNudgeCard`. Surfaces: dashboard capacity strip (last slot + cap),
  pact-wizard step-1 notice at cap, Settings Membership row, weekly-recap founder
  card, milestone-celebration button. **Bug fixed:** pact accept at the cap
  (Dashboard + PactDetail) 402'd into a generic "could not accept" toast; now
  routes to the paywall. Gating lives in `utilities/upgradeNudge.ts`.

## Decisions

- Nudges fail closed on `shouldShowFounderCta` / `isUpgradePurchasable` (same rule as
  the drawer) so nothing advertises an unavailable offer.
- Capacity strip only at `limit-1` and `limit`; earlier is an ad on a daily screen.
- Client-side `HABITS_FREE_HABIT_LIMIT` is a build-time constant; server can drift by
  env. Accepted: the 402 still carries the real limit, so the wall is right even when
  the hint is early/late.
- Celebration CTA only on streak *milestones*, never daily.

## Gotchas

- Container had no node_modules: root `npm ci`, build js-utilities + therr-react,
  then TherrMobile `npm ci` (~5 min total). `therr-react` `npm ci` errors but its
  `lib/` builds fine from root deps.
- `jest.mock` factories may only reference out-of-scope vars prefixed `mock`.
- `Settings.test.tsx` needed the firebase analytics mock once `UpgradeNudgeCard`
  (which imports `analyticsEvents`) entered the Settings import graph.
- Pre-existing lint warnings (inline styles) in CreatePactInvite/PactDetail; zero
  errors after `react/sort-comp` fix in Settings.
