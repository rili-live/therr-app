## Deliverables
- `HabitsWidgetRefreshWorker.kt` — WorkManager `Worker` that boots the React host if cold and
  runs the `HabitsWidgetRefresh` headless task, blocking on a latch until JS reports back.
  Chosen over `HeadlessJsTaskService` because a `startService` from a widget broadcast throws
  on Android 8+ unless temp-allowlisted (vendor/OS dependent); enqueuing work never does, and
  it gets a CONNECTED constraint + Doze deferral for free. `androidx.work:work-runtime-ktx:2.9.1`
  declared explicitly (already transitively present via notifee 2.8 / maps 2.9.1).
- `HabitsWidgetProvider.kt` — asks for a refresh on `onEnabled`, every `onUpdate` tick
  (`updatePeriodMillis` 3h → 30 min, the platform minimum) and on a tap of the new
  `widget_updated` header label ("↻ 5m ago" / "Refreshing…"). Throttle: periodic skips when
  the snapshot is < 5 min old; a `refreshingSince` prefs flag dedups in-flight requests and is
  ignored after 60 s so a dead task cannot pin "Refreshing…".
- `HabitsWidgetModule.kt` — `finishRefresh()` and `hasWidgets()`; set/clear also clear the flag.
- `main/utilities/habitsWidgetRefresh.ts` — the headless task. Plain `fetch` with the stored
  session (`storedSession.ts`, extracted from `backgroundCheckin.ts`), same six reads as the
  dashboard, `today` via new pure `countTodayProgress` in `pactState.ts` (Dashboard now calls
  it). All-or-nothing: any failed input → publish nothing, `finishRefresh()`. 401 = give up.
  `publishHabitsWidget(snapshot, { force: true })` so `updatedAt` moves on an unchanged board.
- `index.js` registers the headless task and runs it from the FCM background handler for
  habits pushes (`shouldRefreshWidgetForPush`); Layout's foreground `onMessage` does the same.
- 6 new snapshot labels in all three dictionaries; 3 new `strings.xml` fallbacks ×3 locales.
- Tests: new `habitsWidgetRefresh.test.ts` (13), `androidHabitsWidget.test.ts` rewritten to
  guard the task key / method names / WorkManager-not-service / tick period / label keys.
- Docs: FEATURES.md widget bullet, HABITS_PROJECT_BRIEF widget v2 line.
