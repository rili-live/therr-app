## Goal
Investigate why the progress-comparison card on the Pact detail screen shows no real stats;
then fix the related dead-code bug it exposed.

## Root cause (one defect, two symptoms)
`createCheckin`'s `if (pactId)` guard is unreachable — a check-in is logged against a habit
goal, never a pact (Dashboard.tsx:185, HabitDetail.tsx:187 both omit pactId). So:
- `habits.pact_members` stat columns stayed at defaults (0 / NULL) → comparison card and
  PactCard rendered zeros; `completePact` picked winners from garbage.
- `habit_checkins.pactId` always NULL → GET /pacts/:pactId/checkins always empty;
  `partnerCheckedIn` push never fired; mid-pact Wing Person credit never landed.
Separately, `incrementCheckinStats` bumps total + completed together and only runs on
completed check-ins → completionRate structurally pinned at 100%.

## Session 2 — Content algorithm abstraction (plan + Phase 1)

### Goal
Estimate LOE and plan making the content algorithm abstractable, so users can pick between
3 named algorithms like the theme picker.

### Key findings
- No single ranker exists: 4 uncoordinated surfaces (docs/ALGORITHM_AUDIT.md). Every tunable
  is a literal in the file using it.
- `main.thoughts` has NO geo columns — the stream cannot be distance-ranked. Geo lives only on
  maps-service surfaces, which have zero interest-awareness. A geo-flavored profile is only
  honest if the map half is in scope.
- `relevanceScore` is frozen onto `main.thoughtReactions` at activation, so switching profiles
  is not a weight swap. Design: denormalize `contentCreatedAt` (recency recomputes live) +
  persist engagement/interest components, blend at read time; indexed fast path when the
  requested profile == the activating one.

### Decisions (user-confirmed)
- Names: **Wander** (local discovery) / **Focus** (declared interests only) / **Pulse** (trending).
- Scope: stream + map surfaces.
- Tunability: env-overridable constants, no DB-backed config.
- Default = PULSE, chosen so the rollout is behavior-preserving.

### Plan
`/root/.claude/plans/estimate-the-level-of-wondrous-hoare.md` — 7 phases, **25–32 days
(~5–6.5 weeks)**. Phases 1–3+5 (~3 weeks) ship a working picker over the thoughts stream.
