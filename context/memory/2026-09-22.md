### Decisions

- User chose "migrate what rolled, then fail" over aborting pre-cluster, and yes to
  standalone mode.
- `MIGRATE_ONLY_SERVICES` set-but-empty ≠ unset. Collapsed with `${VAR:-}`, a first-wave
  failure would migrate *everything* underneath code that never moved. Tested explicitly;
  confirmed non-vacuous by reproducing the naive variant.
- Verify parse fails closed. Unknown `migrate:list` format ⇒ fail the job, never "0 pending".

### Gotchas found

- The backlog's pre-push diagnosis was **incomplete**. `quit()` rejecting at status `wait`
  is only one shape; against a host that is not listening ioredis sits at `connecting` and
  `quit()` *hangs*. The actual hook timeout came from `cleanupTestData` (`client.keys()`
  queued forever) — called from an `after` hook that lacks the `skipTests` guard its
  `beforeEach` has, in both suites. Guarded at module level. A/B proved 2 failing → 0.
- Container had no `node_modules`; root install + building `therr-js-utilities` was needed
  before any tsc. `--legacy-peer-deps` churns `package-lock.json` — reverted, not committed.
