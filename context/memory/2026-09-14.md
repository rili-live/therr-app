### Decisions
- **DM keyboard root cause:** `KeyboardAvoidingView` computes its inset from
  `frame.y + frame.height` vs the keyboard top, learning `y` from a native
  `viewPositionInWindow` call that falls back to *parent-relative* coords. Under
  the app's custom header that fallback under-compensates by the header height —
  enough to bury the whole composer. Keyboard height alone has no such
  dependency. Padding the column (not translating the composer) is what keeps
  the **inverted** FlatList shrinking so the newest message stays visible.
- **Play release notes:** deleted the poll-the-track-after-EAS-Submit race
  rather than tuning its window. Notes are now printed for a manual paste;
  the CircleCI `GOOGLE_PLAY_SERVICE_ACCOUNT_JSON` var is dead (the
  users-service k8s secret of the same name is unrelated and still needed).
- **Streak bar contrast:** old pair was `primary3` on `primary4` = #6E5C85 on
  #5B4273 = **1.4:1**. New pair is a measured one — track = `onSurface` at 16%
  alpha, fill = `brand`, lightened 0.6 in dark mode (a fill dark enough for a
  light track cannot clear 3:1 on a dark one). 4.4/4.3 HABITS, 3.5/4.7 THERR.
- **Reanimated under Jest:** `ChameleonLoader` pulls reanimated into the
  `components/Habits` barrel, whose worklets runtime installs JSI bindings at
  import time → 4 Dashboard suites died. Reanimated v4's own `mock` entry is
  useless (re-exports `src/index`), so `__mocks__/react-native-reanimated.tsx`
  is hand-written like the other seven import-time native mocks.

### Goal

Events (both surfaces, same names): `ios_interest_click` {app, location},
`ios_waitlist_submit` {app, location}.

### Decisions
- `main.emailMarketingSubscribers` stays **identity-shared, NOT brand-scoped**:
  `email` is UNIQUE globally, so a brandVariation read predicate would hide
  subscribers rather than isolate them. Column is provenance only; deliberately
  absent from `BRAND_SCOPED_TABLES`.
- Email is optional in both dialogs. The click count is the demand number;
  signups are a subset. Requiring the email would depress the larger number.
- Closed the missing `validate` on `POST /subscribers/signup` and removed it from
  `validationWiring.test.ts` KNOWN_UNENFORCED — compatibility check done: no
  TherrMobile caller, only web forms posting a typed address.
