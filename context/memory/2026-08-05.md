## Decisions
- **The loop guard is the whole design.** `AuthRoute` attaches `returnTo` only
  when the visitor has no session (`mapStateToProps` mirrors each app's
  `shouldRenderLoginForm` condition). An authenticated-but-under-privileged user
  must get the bare `redirectPath`: Login forwards an already-authenticated
  visitor straight to `returnTo`, which would bounce off the same check forever.
  This also makes the change inert for every cohort except the broken one.
- Residual, logged in WIP: the `/create-profile` hop still drops `returnTo` for
  the authenticated cohort, because of that guard. Fixing it needs a per-route
  opt-in prop, not a hardcoded path in `therr-react`.
- Dashboard hardcoding `translator('en-us', ...)` is correct there; the package
  ships only an en-us dictionary. Mobile was the outlier.
